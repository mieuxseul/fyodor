# Sidecars

## kotatsu-bridge (GPL-3.0)

JSON-lines process that wraps [Kotatsu-Redo/kotatsu-parsers-redo](https://github.com/Kotatsu-Redo/kotatsu-parsers-redo).

Fyodor talks to it over stdin/stdout (`op`: `ping`, `list_sources`, `search`, `details`, `chapters`, `pages`).

See the root README for build steps.
